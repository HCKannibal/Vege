# Учебный веб-проект 
## Описание Веб-сайт создан в рамках практических занятий по разработке веб-ресурсов.
## Основные возможности - Просмотр страниц сайта - Навигация между разделами - Адаптивное оформление 
## Используемые технологии - HTML5 - CSS3 - JavaScript 
## Структура проекта - `index.html` — главная страница - `css/style.css` — файл стилей - `js/script.js` — JavaScript-функции - `images/` — изображения 
## Запуск проекта 1. Клонируйте репозиторий. 2. Откройте папку проекта.
